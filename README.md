# GENO Stuido

Cloudflare Workers와 D1을 사용하는 키오스크 생성기입니다. `/seller`는 판매자 로그인 전용이고, 내보낸 `/shop/{매장주소}`는 고객이 로그인 없이 바로 주문하는 공개 사이트입니다.

```bash
npm install
npm run db:local
npm run dev:full
```

> 이 프로젝트는 API와 D1이 필요한 React/Workers 앱이므로 VS Code의 **Go Live** 대신 `npm run dev:full`로 실행해야 합니다. 출력되는 주소(기본 포트 `8787`)를 브라우저에서 여세요.

## Cloudflare 배포

처음 한 번 Cloudflare에 로그인한 뒤 배포합니다.

```bash
npx wrangler login
npm run deploy
npm run db:remote
```

Wrangler가 첫 배포에서 D1 리소스를 자동 프로비저닝합니다. 이후 사용자, 로그인 세션, 판매자 프로젝트와 주문은 Cloudflare D1에 영구 저장됩니다.

## 제공 기능

- PBKDF2 비밀번호 해시와 HttpOnly 로그인 세션
- 판매자 전용 로그인과 공개 소비자 주문 페이지 분리
- D1 프로젝트 자동 저장
- D1 주문 영구 저장 및 주문 상태 관리
- 판매자별 고유 소비자 사이트(`/shop/{매장주소}`) 발급
- 내보내기에서 판매자·소비자 사이트 주소 복사
- 판매자 주문 목록 5초 자동 갱신
- 브라우저 새 주문 알림
- 프로젝트 JSON 백업 및 복원

## 일일 기록 정책

- 주문·결제시도·판매·환불 기록은 한국시간 자정에 삭제됩니다.
- 판매자 계정, 메뉴, 부서, 디자인 설정은 유지됩니다.
- 주문 화면은 당일 최근 150건을 표시합니다.
- 자정 전에 전체 또는 부서별 Excel용 CSV를 내려받아 마감 자료를 보관하세요.
- 운영 배포에서는 Cron Trigger(`0 15 * * *`, UTC)가 한국시간 자정 정리를 실행합니다.

문자나 카카오 알림톡은 유료 외부 서비스가 필요하므로 포함하지 않았습니다. 현재는 무료 브라우저 알림과 판매자 주문함으로 즉시 알려줍니다.
